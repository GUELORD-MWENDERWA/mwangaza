## Steps

1. Open **Schools**, then **New school**.
2. Enter the name, the code (it becomes the school's address) and the mode: real or demonstration.
3. Create the management's first account.
4. Open the school's page and send it its access letter.

> **Good to know.** A real space is never deleted; only trial and demonstration spaces can be.
