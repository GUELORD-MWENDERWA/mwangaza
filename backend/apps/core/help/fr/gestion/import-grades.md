## Étapes

1. Dans **Saisie des notes**, ouvrez votre cours et la période, puis **Importer depuis Excel**.
2. **Téléchargez le modèle Excel** : un élève par ligne, une colonne par évaluation, les notes déjà saisies comprises.
3. Remplissez les points dans le modèle, sans toucher au matricule ni au nom.
4. Choisissez le classeur, puis **Contrôler** : chaque ligne est vérifiée.
5. Si tout est juste, confirmez : les points vont dans la fiche, comme une saisie à la main.

> **À savoir.** Une seule ligne fausse et rien n'est enregistré : corrigez le classeur et renvoyez-le. Une case vide ne change pas la note déjà saisie.

---

## Questions fréquentes

**Un élève introuvable ?** Il est reconnu par son matricule, ou par son nom exact dans la classe.

**Sans internet ?** Le contrôle demande le réseau ; l'enregistrement, lui, peut attendre le réseau comme une saisie ordinaire.
