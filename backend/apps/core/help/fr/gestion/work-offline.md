## Étapes

1. Connectez-vous une première fois avec internet, sur l'appareil que vous utiliserez.
2. Ouvrez **Préparer l'appareil** dans le menu et attendez la fin du téléchargement.
3. Travaillez normalement. L'indicateur de synchronisation en haut montre ce qui attend d'être envoyé.
4. Quand internet revient, l'envoi se fait tout seul.

> **À savoir.** Les paiements et les notes saisis hors ligne ne sont jamais perdus ni comptés deux fois.

---

## Questions fréquentes

**Combien de temps tient l'appareil sans réseau ?** Aussi longtemps que vous le voulez, tant que vous ne videz pas les données du navigateur.

**Un message demande mon code PIN ?** Saisissez-le : il protège l'appareil quand il est resté hors ligne.
