## Noter une exception

On part de l'horaire publié : on ne note que ce qui ne s'est pas passé comme prévu.

1. Ouvrez **Heures prestées**, choisissez le mois.
2. **Noter une exception** : date, heure de l'horaire, puis le type : enseignant absent, remplacé (choisir le remplaçant), cours annulé ou heure en plus ; ajoutez le motif.
3. L'onglet **Exceptions du mois** les liste ; une exception se **annule** (elle reste dans le journal).

## Lire et imprimer

- **Par enseignant** : prévues, absentes, annulées, remplacements faits, heures en plus, **prestées**.
- **Fiche** : le PDF d'un enseignant pour le mois ; **Exporter (Excel)** : tout le mois.

> **Bon à savoir.** Les congés du calendrier de l'école ne sont pas comptés. Un cours commun à plusieurs classes compte pour une heure. Le total est recalculé à chaque ouverture, il n'est jamais saisi à la main.

---

## Questions fréquentes

**Qui peut noter ?** Les personnes qui ont le droit « Noter les heures non données » ; l'école le donne dans **Rôles**.

**Une erreur ?** Annulez l'exception et notez la bonne.
