## Étapes

1. Ouvrez le **registre des reçus** et retrouvez le paiement.
2. Cliquez sur **Demander l'annulation** et écrivez le motif.
3. La personne autorisée (comptable ou direction) approuve ou refuse.
4. Une fois approuvée, un reçu d'annulation est établi ; le solde de l'élève est rétabli.

> **À savoir.** Un paiement n'est jamais effacé : l'annulation est un nouvel enregistrement lié, avec le motif et l'auteur.

---

## Questions fréquentes

**Qui peut approuver ?** Les rôles qui ont la permission d'approuver les annulations ; la direction règle cela dans **Rôles**.
