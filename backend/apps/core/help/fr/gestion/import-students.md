## Étapes

1. Ouvrez **Élèves**, puis **Importer**.
2. Téléchargez le modèle Excel, remplissez-le, enregistrez-le.
3. Envoyez le fichier : l'application montre un aperçu et signale les lignes à corriger.
4. Corrigez dans Excel et renvoyez, ou confirmez l'import.

> **À savoir.** Un import se défait : **Annuler cet import** retire les élèves créés, tant qu'aucun paiement ne leur est lié.

---

## Questions fréquentes

**Les noms avec accents ?** Ils sont gardés tels quels.

**Une ligne est refusée ?** Le message dit la ligne et la raison (date illisible, classe inconnue…).
