## Étapes

1. Ouvrez l'adresse de votre école (le nom de l'école est dans l'adresse).
2. Saisissez votre numéro de téléphone et votre mot de passe.
3. Si votre compte a la double authentification, saisissez le code à 6 chiffres de votre application d'authentification.
4. À la première connexion, choisissez un nouveau mot de passe.

> **À savoir.** Sur un ordinateur partagé, déconnectez-vous en partant : le menu de votre nom, puis **Se déconnecter**.

---

## Questions fréquentes

**Mot de passe oublié ?** Demandez à la direction ou à la personne qui gère les comptes de vous en donner un nouveau.

**Le code est refusé ?** Vérifiez l'heure de votre téléphone : elle doit être exacte.
