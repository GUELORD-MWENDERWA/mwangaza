## Étapes

1. Ouvrez **Facturation**.
2. Consultez les abonnements et les factures en attente.
3. Émettez la facture d'une école ; enregistrez son paiement quand il arrive.

> **À savoir.** Les factures émises ne se modifient pas ; une erreur se corrige par une note de crédit.
