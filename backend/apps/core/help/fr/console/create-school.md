## Étapes

1. Ouvrez **Écoles**, puis **Nouvelle école**.
2. Saisissez le nom, le code (il devient l'adresse de l'école) et le mode : réel ou démonstration.
3. Créez le premier compte de la direction.
4. Ouvrez la fiche de l'école et envoyez-lui sa lettre d'accès.

> **À savoir.** Un espace réel ne se supprime jamais ; seuls les espaces d'essai et de démonstration peuvent l'être.
