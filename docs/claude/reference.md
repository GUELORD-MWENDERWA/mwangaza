# Référence — commandes en détail et adresses en développement

Sorti de `CLAUDE.md` le 2026-10-04 : `CLAUDE.md` est lu à chaque conversation, il doit rester court. Ici, le détail, à lire au besoin (`grep -n`) et **à tenir à jour dans la PR de chaque tâche** qui ajoute un écran, une API, une commande ou des données à `make demo`. ## Commandes en détail

| Commande | Effet |
|---|---|
| `make dev-local` | Django et Vite sur la machine (valeurs dans `.env`, copié de `.env.example`) ; recette en bash pour que Ctrl+C arrête proprement les quatre serveurs ; Vite lancé app par app (`pnpm dev` afficherait un faux échec à l'arrêt) |
| `make services` | seulement PostgreSQL et Redis dans Docker, prêts (`--wait`) ; rarement utile : la cible cachée `db-up` les démarre avant `dev-local`, `migrate`, `makemigrations`, `demo`, `superuser`, `shell` et `test-back` (pas en CI, où `CI` est défini) |
| `make reset-db` | efface la base de développement de Docker (et celle des tests : `down --volumes`), puis `make migrate demo` ; pour une base qu'une migration ne peut plus suivre (`InconsistentMigrationHistory`, ex. nouveau modèle de compte en 1.2) |
