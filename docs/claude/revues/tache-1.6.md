## Points relevés pendant la tâche

- La maquette de connexion masque l'encadré de l'école sous 900 px : sur téléphone, l'écran n'aurait montré que « Mwangaza ». L'école (logo ou code, nom) est ajoutée en une ligne sous la marque.
- `virtual:pwa-register/react` de vite-plugin-pwa importe `workbox-window`, absent de la liste acceptée : le build échouait. Enregistrement du service worker écrit dans l'application (une trentaine de lignes), le service worker généré accepte déjà le message `SKIP_WAITING`.
- `make test-e2e` avec des serveurs lancés par Playwright restait bloqué à la fin : `pnpm exec vite` (pnpm 12) lance Vite hors du groupe de processus que Playwright arrête, qui attendait alors sans fin (la CI aurait tourné jusqu'à sa limite). Vite lancé directement (`./node_modules/.bin/vite`) ; disponibilité vérifiée sur `127.0.0.1` (les serveurs n'écoutent pas en IPv6). Vérifié : 8 parcours, fin propre, ports libérés.
- `openapi-typescript` plante avec TypeScript 7 : `packages/api` garde TypeScript 6.
- Chromium de Playwright téléchargé sur la machine (~115 Mo, `~/.cache/ms-playwright`) : action notée dans `A-FAIRE.md` pour l'utilisateur.
- Le JavaScript de la Gestion fait 763 Ko (239 Ko compressé) : avertissement de Vite ; découpage par écran à envisager quand les écrans arrivent (2.x, 3.x).
