## Points relevés pendant la tâche

- Libellé « New password » traduit par le catalogue de Django dans le schéma OpenAPI (le reste en anglais) : libellé propre au projet.
- Django change le jeton CSRF à la connexion : l'application (1.6) doit relire le cookie après chaque étape réussie (noté dans `03` § 8).
- Une vue d'étape en POST seul affichait « Method not allowed » dans l'API navigable : chaque étape répond aussi en GET avec l'étape en cours (utile aussi après un rechargement de page).
- Les essais ratés bloquaient les essais en développement pendant 15 minutes : `make demo` les efface.
