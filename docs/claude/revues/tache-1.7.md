## Points relevés pendant la tâche

- Un service modifiait l'objet en mémoire avant de vérifier la règle : un refus laissait l'objet changé. Les services vérifient maintenant d'abord, puis modifient (années, niveaux, options, classes).
- `tailwind-merge` retirait le fond blanc des listes de choix (`bg-card`) à cause de la position de la flèche écrite `bg-[…]` : écrit `bg-position-[…]` et `bg-[image:…]`.
- Les grilles à une colonne laissaient un tableau large imposer sa largeur (journal : 1 691 px au lieu de 1 440, 843 px sur téléphone) : colonnes `minmax(0, …)`, le tableau défile dans sa carte.
- Le libellé d'un cycle avait changé après la génération de la migration (tiret) : migration 0004 corrigée avant la fusion (`makemigrations --check` propre).
- Envoi d'un fichier dans les tests d'écrans : le `Request` de Node ne lit pas le `FormData` de jsdom ; le test du logo utilise ceux de Node.
- Un parcours ancien (« mot de passe provisoire ») a montré une page blanche une fois sur trois passages (serveur Vite de développement), sans se reproduire ; la CI refait un parcours raté une fois.
- JavaScript de la Gestion : 883 Ko (260 Ko compressé), +12 Ko compressés pour 5 écrans ; découpage par écran toujours à envisager.
