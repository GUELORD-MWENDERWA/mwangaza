## Points relevés pendant la tâche

- `entity_label` d'un rôle système sans nom propre : vide (comme `name` dans `/api/roles/`) ; l'interface affiche le nom traduit du code du rôle `entity_id` (un rôle système ne se supprime pas).
- Le journal ne s'efface pas : les entrées des essais restent dans la base de développement ; `make demo` n'y touche pas, `make reset-db` repart de zéro. Une école ou un compte cité dans le journal ne se supprime plus dans l'administration Django (on suspend, on désactive) : noté dans `A-FAIRE.md` § 12.
- Derrière le proxy de Vite (et plus tard Caddy), l'adresse IP notée est celle du proxy (127.0.0.1 en développement) : même réglage que la limitation des tentatives, en 4.6.
