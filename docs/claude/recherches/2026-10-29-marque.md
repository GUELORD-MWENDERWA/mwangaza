# Marque Mwangaza — références (lot 1, BRAND.1)

2026-10-29. But : apprendre des marques reconnues avant de proposer trois pistes (`maquettes/marque/pistes.html`).

## Ce qui a été regardé

| Marque | Ce qu'on retient |
|---|---|
| Livre de marque Ujuzi (modèle fourni, LORD STUDIO, 2026) | structure du livre : fondation stratégique, concept, construction, versions, interdits, palette avec proportions (60 / 20 / 12 / 8), typographie, mise en page, photo, applications ; un bleu profond, un accent chaud rare ; un point d'accent comme signature |
| PowerSchool (charte 2025) | une couleur propriétaire (cyan) sur fond clair, version marine réservée au contraste ; assemblages du logo fournis, jamais recomposés |
| Rawbank (nouvelle identité, avril 2025) | symbole tiré du Congo (léopard) avec un logotype plein ; le jaune réservé aux griffes (vitalité, espoir) : l'accent sur une petite surface |
| Equity BCDC (identité de la fusion, 2021) | une couleur dominante portée partout (agences, cartes, application) : reconnue de loin |
| Orange, Orange Money | un carré plein d'une seule couleur suffit comme marque, lisible à toute taille |
| M-Pesa (Vodacom) | une couleur dominante, un symbole simple qui tient dans une icône de téléphone |
| GitHub | symbole plein dans un disque, monochrome possible, reconnu à 16 px (déjà retenu le 2026-10-14) |
| Duolingo, ClassDojo | mascotte et couleurs vives : bien pour des enfants, trop léger pour un comptable ou un préfet → écarté |

## Leçons pour Mwangaza

1. Posséder **un bleu** ; le blanc domine ; l'accent est rare (≤ 5 % de la surface) — répond au « site jaunâtre ».
2. Symbole plein et épais dans une forme de fond (demande du 2026-10-14), lisible à 16 px, qui marche seul (icône du téléphone).
3. Un ancrage qui a du sens ici (Rawbank : le léopard ; Mwangaza : la lumière, le Kivu, l'école).
4. Livrer les assemblages et les interdits, comme PowerSchool et Ujuzi.
5. À éviter : dégradés, violet, étincelles (lues aujourd'hui comme « IA »), mascottes, illustrations générées.
