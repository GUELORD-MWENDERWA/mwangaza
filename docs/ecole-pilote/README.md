# École pilote — ITIG Don Bosco Goma

Tout ce qui concerne l'école pilote : ce qu'on sait déjà (`fiche-itig.md`), les documents reçus et ceux qu'on attend.

## Où déposer tes documents

**Dépose tout dans `depot/`**, sans te soucier du nom ni du format (photo, PDF, Excel, Word, note). Puis dis dans Claude Code : `/document-ecole`. Claude lit le fichier, le renomme, le range, compare avec les documents du projet et met à jour le suivi.

| Dossier | Contenu | Git |
|---|---|---|
| `depot/` | ce que tu déposes, pas encore trié | **non** (jamais envoyé sur GitHub) |
| `documents/` | documents rangés **sans** données personnelles : logo, grille des frais, modèles vierges | oui |
| `prive/` | documents **avec** données personnelles : liste des élèves, noms du personnel, salaires, reçus remplis | **non** |

Nom des fichiers rangés : `AAAA-MM-JJ-sujet.ext`. Les données de démonstration et les tests restent toujours fictifs.
