# Documents de l'école pilote — ITIG Don Bosco Goma

Ce dossier reçoit les documents **réels** de l'ITIG (cahier des charges § 11). Ils servent à ajuster les maquettes, le modèle de données et les données de démonstration. Pour les intégrer : `/document-ecole` dans Claude Code.

## Règles

- Fichiers **sans** données personnelles (grille des frais, modèle vierge de reçu ou de bulletin, logo, en-tête) : ici, suivis par Git.
- Fichiers **avec** des données personnelles (liste des élèves, grille salariale nominative, reçus remplis) : dans `prive/`, ignoré par Git. Ne jamais les copier ailleurs dans le dépôt ni dans les tests ; les données de démonstration restent fictives.
- Nommer les fichiers : `AAAA-MM-JJ-sujet.ext` (ex : `2026-09-30-grille-frais-2026-2027.pdf`).
