# @mwangaza/i18n

Traductions fr / en (i18next) partagées par les applications (Gestion, Portail, console) — tâche 1.6.

La langue choisie est aussi posée dans le cookie `django_language` (tâche 4.5.2) : le serveur répond dans la même langue (messages, PDF, Excel), quelle que soit celle du navigateur.

Le nom de la plateforme n'est écrit dans aucun texte : `{{platform}}`, remplacé par `setPlatformName` (tâche 5.1) avec le nom lu dans ses paramètres.
