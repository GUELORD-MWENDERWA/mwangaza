Un compte est unique sur la plateforme : il peut être du personnel de plusieurs écoles et parent de familles de plusieurs écoles. Un compte « Plateforme » (super-admin) ne se change pas ici : administration Django.
Mot de passe provisoire : seulement pour un compte du personnel (au moins une école active) — le portail refuse un mot de passe provisoire ; un parent qui a oublié le sien demande un nouveau code famille à son école. Réinitialiser la double authentification : seulement si elle est activée. Désactiver (après confirmation) : plus de connexion nulle part, sessions fermées ; on ne supprime jamais un compte.
