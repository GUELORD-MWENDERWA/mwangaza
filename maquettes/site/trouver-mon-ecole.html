Ouvrir l'espace parents
Trouver mon école (WEB.1b) : formulaire GET vers la vue existante school_space : code mis en minuscules, vérifié par la même règle que les codes d'école, puis redirection vers https://<code>.<domaine>/app/. Aucune recherche en base : ni liste publique ni moyen de deviner quelles écoles existent ; un code inconnu arrive sur la page « Aucune école à cette adresse » de la Gestion (déjà faite). Code mal formé : on revient ici, champ en erreur « Lettres, chiffres et tirets seulement ». Animation 7 — rassurer avant de partir : la ligne « Vous allez ouvrir… » se met à jour à chaque lettre tapée (quelques lignes de JavaScript ; sans JavaScript, la ligne n'est pas affichée). Le dernier code utilisé est proposé au retour (stockage du navigateur, sur cet appareil seulement).
