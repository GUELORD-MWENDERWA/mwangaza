Les bulletins de la première période arrivent chez les parents

Dès que l'école publie les bulletins, chaque parent les voit dans son espace, avec la place et la conduite.

28 octobre 2026Par l'équipe Mwangaza2 min de lecture

La première période se termine dans beaucoup d'écoles du Nord-Kivu. Les titulaires ont saisi les points, la délibération est faite : il reste à remettre les bulletins aux familles.

Ce que voit le parent

Dans l'espace parents, la fiche de chaque enfant montre maintenant :

  • le bulletin de la période, au format de l'école ;
  • le pourcentage, la place et la conduite ;
  • le code QR qui prouve que le bulletin est vrai.

Ce que fait l'école

La direction choisit le moment : rien n'est visible avant qu'elle publie. Elle peut retenir le bulletin d'un élève, par exemple pour une correction. Le détail est dans le guide de la Gestion.
