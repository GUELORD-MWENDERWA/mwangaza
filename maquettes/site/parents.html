Accès

Trois étapes, une seule fois

Votre compte est créé par l'école. Vous l'activez avec le code famille qu'elle vous donne.

  1. Le code famille

    Sur la fiche d'inscription, ou au secrétariat.

    ExempleK7M-4QP

  2. Votre téléphone

    Ouvrez parents.mwangazaschool.com et tapez le numéro donné à l'école.

  3. Votre mot de passe

    Choisissez-le. Ensuite, le numéro et le mot de passe suffisent.

Sur Android (Chrome) ou iPhone (Safari), « Ajouter à l'écran d'accueil » le met à côté de vos applications, sans passer par un magasin.

Questions

Votre école n'utilise pas encore Mwangaza ?

Parlez-en à la direction, ou donnez-nous son nom : nous la contactons.

Proposer mon école
J'ai perdu le code famille

Demandez-en un nouveau au secrétariat de l'école : l'ancien ne marche plus.

J'ai changé de numéro

Signalez-le à l'école, ou depuis votre profil si vous êtes encore connecté : l'école valide le changement.

Mes enfants sont dans deux écoles

Un seul compte suffit si les deux écoles utilisent Mwangaza avec le même numéro.

Peut-on payer depuis le téléphone ?

Pas encore : on paie à la caisse de l'école. Le paiement par Mobile Money est prévu.

Questions des parents : console (SITE.1a, page « parents »). Appel final pour un parent : proposer son école (formulaire de la page Contact).
