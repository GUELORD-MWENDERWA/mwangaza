Espace parents

Suivez l'école de vos enfants sur votre téléphone

Paiements, reçus, ce qui reste à payer, annonces et convocations : tout ce que l'école partage avec vous, pour chaque enfant, même dans des écoles différentes.

Ce que vous voyez

L'essentiel de l'école, sans vous déplacer

Paiements et reçus

Chaque paiement, son reçu, et ce qui reste à payer par tranche.

Annonces

Les communiqués de l'école, sans papier perdu dans le cartable.

Calendrier et convocations

Congés, réunions, examens, et les convocations qui vous concernent.

Alertes sur l'écran

Paiement reçu, échéance proche : vous êtes prévenu sur le téléphone.

Fonctions citées : seulement celles livrées. Résultats et bulletins dans l'espace parents : ajoutés ici quand la tâche 8.8 est livrée (jamais annoncés avant). Vignettes : haut de chaque écran du Portail.
Activer votre compte

Trois étapes, une seule fois

Votre compte est créé par l'école. Vous l'activez avec le code famille qu'elle vous donne.

  1. Le code famille

    Il est imprimé sur la fiche d'inscription de votre enfant, ou donné par le secrétariat.

    Code familleK7M-4QP

  2. Votre téléphone

    Ouvrez parents.mwangazaschool.com, tapez le numéro donné à l'école et le code famille.

  3. Votre mot de passe

    Choisissez-le. La prochaine fois, le numéro et le mot de passe suffisent.

Activation : parcours existant du Portail (H1, portail/activation) ; code famille fictif. Code perdu : l'école en donne un nouveau (portail/mot-de-passe-oublie).
Sur votre écran d'accueil

Comme une application, sans magasin

L'espace parents s'ajoute à l'écran d'accueil et s'ouvre d'un geste. Il prend très peu de place.

Android (Chrome)

  1. Ouvrez parents.mwangazaschool.com dans Chrome.
  2. Touchez le menu ⋮ en haut à droite.
  3. Choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».

iPhone (Safari)

  1. Ouvrez parents.mwangazaschool.com dans Safari.
  2. Touchez le bouton Partager.
  3. Choisissez « Sur l'écran d'accueil ».
Vos données

Vous ne voyez que vos enfants

  • L'école décide de ce qu'elle partage ; elle peut suspendre un compte.
  • Votre mot de passe n'est connu que de vous.
  • Chaque reçu porte un code QR que tout le monde peut vérifier.
Lire la politique de confidentialité
J'ai perdu mon code famille

Demandez-en un nouveau au secrétariat de l'école : l'ancien ne marche plus.

J'ai changé de numéro de téléphone

Signalez-le à l'école, ou depuis votre profil si vous êtes encore connecté : l'école valide le changement.

Mes enfants sont dans deux écoles

Un seul compte suffit si les deux écoles utilisent Mwangaza avec le même numéro.

Puis-je payer en ligne ?

Pas encore : on paie à la caisse de l'école. Le paiement par Mobile Money est prévu.

Votre école utilise Mwangaza ?

Ouvrez l'espace parents avec le numéro donné à l'école. Pas encore de code ? Demandez-le au secrétariat.
