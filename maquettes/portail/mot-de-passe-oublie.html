Choisir un nouveau mot de passe

Mwangaza n'envoie pas de SMS. Pour prouver que vous êtes le parent, il vous faut un nouveau code famille.

1Passez au secrétariat de l'école d'un de vos enfants, avec votre pièce d'identité.
2Le secrétariat imprime un nouveau code famille. L'ancien ne marche plus.
3Saisissez-le ici et choisissez votre nouveau mot de passe.
Enregistrer et me connecter
M19 · H1 (tâches 4.4, 2.1) : le nouveau code est créé depuis la fiche famille (M10, « Nouveau code ») ; il ne sert qu'une fois et expire après 30 jours s'il n'est pas utilisé (durée à confirmer). Le numéro doit être celui du tuteur principal de la famille. Après le changement, les autres téléphones connectés sont déconnectés. Mêmes limites d'essais que la connexion. Plus tard (V2) : code par SMS, en option.
