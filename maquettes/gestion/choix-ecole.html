Le nom de l'école, en haut du menu, s'ouvre sur la liste des écoles du compte. Il n'apparaît que si le compte a plus d'une école.

M2 · B3 (tâches 1.2, 1.6) : affiché après la connexion depuis l'adresse générale, ou depuis « Toutes mes écoles… ». Une seule école → pas d'écran de choix. Seules les écoles où le compte a un rôle actif sont listées ; école suspendue : visible mais grisée (A1). Ouvrir une école = aller sur son adresse {code}.mwangaza.cd/app ; les rôles, le menu et les données changent. Le rôle « Parent » renvoie vers le portail familles. Hors-ligne : seule l'école dont les données sont sur l'appareil reste disponible.
