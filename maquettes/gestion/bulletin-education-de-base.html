Bulletin du 1er semestre : seules les colonnes 1re P, 2e P, EXAM. et TOT. du 1er semestre sont remplies ; le reste attend le 2d semestre. Les mentions de décision restent vides jusqu'à la délibération de fin d'année.
Programme officiel du cycle terminal de l'éducation de base (2019) : 36 h par semaine, en domaines — sciences (algèbre, arithmétique, géométrie, statistique ; botanique, anatomie, zoologie ; sciences physiques, technologie, TIC), langues (français, anglais), univers social (éducation civique et morale, géographie, histoire), arts (musique, dessin), développement personnel (éducation physique). Si l'ITIG utilise un bulletin par domaines, le même moteur l'affichera (voir « Cours et maxima »).
Questions pour l'ITIG (I15, Q10–Q11) : 1. Les formulaires officiels numérotent encore les classes à l'ancienne (« 3e année » = 1re des humanités ; « 1re année secondaire » = 7e EB) : même chose à l'ITIG ? 2. L'école remplit-elle le bulletin officiel pré-imprimé (acheté) — Mwangaza imprime alors seulement les notes aux bons endroits — ou peut-elle imprimer le bulletin complet ? 3. Code de l'école (7 chiffres), N° ID et N° permanent des élèves. 4. Mentions APPLICATION / CONDUITE utilisées (E, TB, B, AB, M…).
