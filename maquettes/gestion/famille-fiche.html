Si le parent n'a plus son code

Réimprimer le code : même code, pour un parent qui n'a pas encore activé son compte ou qui l'a égaré.

Nouveau code : l'ancien code ne marche plus. Le parent s'en sert pour choisir un nouveau mot de passe (« Mot de passe oublié » du portail).

M10 · D4, H1 (tâches 2.1, 2.2, 4.4) : code famille de 8 caractères sans caractères ambigus (pas de 0/O, 1/I/L), unique sur la plateforme, affiché en 2 × 4. « Nouveau code » : permission students.edit, confirmation, audit ; l'ancien code est invalidé, le compte parent reste actif. La famille appartient à l'école (Family lié à l'école, décision Q10) : seulement les enfants de cette école. Si la famille a aussi des enfants dans une autre école, celle-ci a sa propre fiche et son propre code, jamais visibles d'ici ; le parent relie les deux dans le portail. Changer de tuteur principal = nouveau code à remettre au nouveau tuteur. « Suspendre l'accès » coupe le portail sans supprimer le compte.
