SupprimerAnnulerEnregistrer
5.7 : tout le personnel lit le calendrier ; l'écrire demande announcements.publish (sans ce droit : ni « Ajouter » ni « Modifier »). Le formulaire s'ouvre dans une fenêtre. Fin vide : une seule journée ; heure vide : toute la journée ; la fin ne peut pas être avant le début. « Personnel seulement » : jamais dans le portail parents. Un événement se corrige et se supprime (ce n'est ni de l'argent ni une note). Pas de notification à chaque événement : pour prévenir les familles, publier une annonce.
